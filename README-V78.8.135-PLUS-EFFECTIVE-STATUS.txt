PricePulse V78.8.135 — Plus effective status clarity

Base: V78.8.134 preserved.
Only Admin Plus status display was changed.

- Individual Mode: shows the selected user’s own ACTIVE / PENDING / AVAILABLE / EXPIRED state.
- Master OFF: selected-user status area shows PAUSED BY MASTER. The individual membership record is preserved and not converted to expired.
- Master ON: selected-user status area shows ACTIVE VIA MASTER. The underlying individual status is preserved.
- Return to Individual Mode: the selected user’s original individual status is shown again.

No Plus popup, Wishlist, Deal Alerts, auth, catalog, capture, product, pricing, or other approved logic/design was changed.
