PricePulse V74 — Signup / Sign In Flow

Base: V73.5 Wishlist locked.
Wishlist logic/design untouched.

Changes:
- Header stays Sign In.
- Sign In modal has Google + email OTP and a Create Account switch.
- Create Account modal has Google + email OTP and a Sign In switch.
- Email signup creates a user; email sign-in does not create a new user.
- New/incomplete users proceed to Complete Profile.
- Profile fields start blank for a new user except authenticated email.
- Mobile and PIN placeholders are generic, not sample personal data.
- Country starts at Select Country and must be selected.
- Existing complete users sign in directly without profile setup.
